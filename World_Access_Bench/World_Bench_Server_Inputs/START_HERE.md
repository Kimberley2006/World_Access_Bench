# World_Bench 服务器输入总包

本包包含执行最终数据构建计划所需的现有数据。它不是已经生成并完成物理标注的最终训练集。任务、候选计划与结果文件的状态必须分别统计。

## 已包含

- 97条原始MP4，SHA-256已核对。
- 277条正式任务及固定场景分组划分。
- 157张历史源视频证据图。它们是回查材料，不是编辑结果标签。
- 1662个正式生成任务：H3-Base-Ref2VA、Wan1.3B+FlowEdit、Wan1.3B+FlowAlign，每种方法各用4101/4102两个种子。
- 194条已生成的慢放/冻结MP4，以及831个任务—结果诊断配对记录。原片不修改对照复用97条原MP4。
- 数据核验脚本、生成配置登记表、结果与标注模板、自动标注协议、验收条件和排除记录。

没有包含：模型权重、服务器本地路径、已绑定的推理启动命令、正式编辑模型输出、正式物理标签。不能将generation/jobs.jsonl中的计划行当作训练样本。

## 解压后先检查

```bash
cd World_Bench_Server_Inputs
python3 tools/verify_inputs.py
```

此命令只核验已打包的输入数据、文件哈希、划分和计划一致性，不运行模型，也不会宣称最终训练集完成。实际状态见PACKAGE_STATUS.json。

## 交给服务器Codex执行

阅读SERVER_PLAN.md与protocols/ANNOTATION_PROTOCOL.md。先检查服务器现有H3和Wan推理代码、模型目录及可用GPU，补齐generation/backends.json的本地路径、启动参数、版本和权重哈希；不要猜测路径。接着适配三种编辑方法、运行全部生成任务、记录真实结果，再完成两路AI物理标注和分歧复查。未评估字段不能伪装成uncertain或fail，运行失败不能变成物理负例。

保持本包任务、时长和划分，不临时删改指令。若实际接口不支持某个任务，明确登记unsupported及原因。失败重试有上限，并保留所有尝试。生成、标注、验收全部完成后，才输出final/train.jsonl、validation.jsonl和test.jsonl。

## 避免混用旧包

本包落实最新的“六条自然编辑候选”计划，替代之前用于执行的输入清单。旧的“3自然输出+3对照”不再是正式六候选配置。diagnostics中的标签属于旧规格下的局部程序标签，明确留存旧spec_revision，不自动升级成当前任务的正式标签。训练时只读取最终通过验收的final清单；provenance与diagnostics不应被递归扫描进正式训练集。

统一采用视频实际呈现时间戳，不能把原帧号直接当结果帧号。全片冻结、变速或画质异常本身不构成物理违规标签。
